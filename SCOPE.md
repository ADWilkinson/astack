# Scope

astack covers the product loop: getting context, planning, building interfaces and graphics that don't look generated, using the product for real, measuring it, shipping it, proving it's live, telling people, launching and automating the repeat work.

A skill earns a place when a capable model, without it, reliably gets a real task wrong, and the skill fixes that. Frequent work isn't enough on its own; the model has to need the help. A short procedure can qualify. A script earns its place when it does something the model can't do by reading: drive a browser, query the exact PR head, compute geometry, scan a tree.

Out of scope:

- general coding advice the model already follows;
- wrappers that just call another skill;
- private fleet configuration, model rosters or anyone's personal accounts;
- copied vendor manuals;
- blanket bans on fonts, colours or frameworks. Name the default, say why it reads as generated, and let the brief win.
