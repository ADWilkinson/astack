# context

## What it does

Reads the threads, issues, PRs, git history, live product and analytics that change a task, and reconciles them into a brief of under 20 lines.

## When to reach for it

Picking up a ticket, a Slack ask, someone else's branch, or any task where decisions and corrections live outside the prompt.

## It's working if

The brief has an Outcome, Decided items with links and dates, a Starting state that was observed, and an Open line naming the one unknown and how to settle it.

## Common questions

**Does it copy messages into the repo?** No. It links to sources and keeps private material out of commits and PRs.
