# web-graphics

## What it does

Builds isometric, flat, ASCII, halftone, diagram and social-card graphics in code, with a scene compiler for isometric projection and depth order.

## When to reach for it

Hero illustrations, explainer visuals, icon sets, OG images, anything where stock art would look generic.

## It's working if

You get editable source next to the export, the graphic was inspected at its smallest real size in both themes, and nothing in it pretends to be data the product does not have.

## Common questions

**Does it use image generation?** Only for photographic or painterly texture, and it says so. Everything else is SVG, CSS or canvas.
