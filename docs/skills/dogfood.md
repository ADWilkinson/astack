# dogfood

## What it does

Walks real user journeys to the real outcome, keeps a findings frontier, fixes what breaks and replays until the journeys pass.

## When to reach for it

"Test it like a customer", pre-launch QA, after a big change, AI features that need repeated trials.

## It's working if

Each journey ends at a checked outcome (the record, the email, the page), each finding has a repro, cause, fix and replay, and anything unreachable is named.

## Common questions

**Will it sign in as someone else?** No. It uses the account and session you selected.
